# 六爻起卦 · Liuyao Divination

一个单文件、零依赖、可离线的六爻起卦网页。

写完直接双击打开就能用，不需要装 node、不需要起本地服务、不需要联网。也可以直接扔到任意静态服务器上。

## 它做什么

按传统六爻起卦的流程走一遍：

1. **摇六爻** —— 三枚硬币摇六次，自下而上，得初爻到上爻
2. **定四象** —— 数三枚硬币里「背面」的个数
   - 0 背 → 老阴（6）`⚋ ×`
   - 1 背 → 少阳（7）`⚊`
   - 2 背 → 少阴（8）`⚋`
   - 3 背 → 老阳（9）`⚊ ○`
3. **排卦** —— 按上下卦查表定出本卦
4. **取动爻** —— 老阴、老阳为动爻，阴阳互变后得到变卦
5. **取互卦** —— 本卦二三四爻为下卦、三四五爻为上卦，重组成互卦

结果输出本卦、动爻、变卦、互卦四项，可一键复制带走。

## 用法

### 方式一：直接打开

下载 `index.html`，双击。完事。

### 方式二：起个静态服务

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

### 方式三：部署到静态托管

任何静态托管都能直接放：

- GitHub Pages：把 `index.html` 推到仓库根目录，在 Settings → Pages 里选分支即可
- 阿里云 OSS / 轻量服务器 / Nginx：把 `index.html` 丢进站点根目录

## 两种摇卦模式

| 模式 | 说明 |
|---|---|
| **点击摇钱** | 浏览器生成随机数，再混入你点击的时间和屏幕位置。是个仪式，不是物理意义上的天意 |
| **我用真硬币** | 你自己抛三枚真硬币，数出背面个数填进去。结果完全由你的手决定 |

界面里说明了这一点，没有把随机数包装成「天意」。这一点是刻意保留的。

## 功能

- ✅ 自由输入问题，不限内容
- ✅ 最近问过的问题存成标签，最多 8 条，点一下接着摇
- ✅ 撤销上一爻，摇错一爻不用整卦重来
- ✅ 本卦 / 动爻 / 变卦 / 互卦四项完整输出
- ✅ 单卦复制、单条删除、一键清空全部
- ✅ localStorage 持久化，刷新不丢记录
- ✅ 移动端适配

## 数据存放

所有记录只存在你自己浏览器的 localStorage 里。

- 键名 `liuyao_state_v1`（卦与爻）、`liuyao_recent_v1`（最近问题）
- 不发送到任何服务器，没有埋点，没有统计
- 点「清空全部记录」即删，没有云端副本

键名带了版本号，以后改数据结构不会读到旧格式。

## 卦象逻辑

核心对应关系写在 `index.html` 的 `// ==CORE START==` 与 `// ==CORE END==` 之间，可以单独抽出来跑：

```js
const TRI={"111":"乾","110":"兑","101":"离","100":"震","011":"巽","010":"坎","001":"艮","000":"坤"};
// GRID[upper][lower] -> [卦序, 卦名]
```

- `toBits(vals)` —— 六爻数值转 0/1（阳为 1，阴为 0）
- `hexOf(bits)` —— 0/1 数组转卦象
- `changedBits(vals)` —— 求变卦（动爻阴阳互换）
- `isMoving(v)` —— 判断是否动爻（6 或 9）

### 验算

卦名对应六十四个组合，肉眼查不出对错，所以用一组已知答案验算过：

| 情况 | 六爻（自下而上） | 期望 |
|---|---|---|
| 纯阳 | 7 7 7 7 7 7 | 乾为天（第 1 卦） |
| 纯阴 | 8 8 8 8 8 8 | 坤为地（第 2 卦） |
| 下乾上坤 | 7 7 7 8 8 8 | 地天泰（第 11 卦） |
| 下坤上乾 | 8 8 8 7 7 7 | 天地否（第 12 卦） |
| 下离上坎 | 7 8 7 8 7 8 | 水火既济（第 63 卦） |
| 下坎上离 | 8 7 8 7 8 7 | 火水未济（第 64 卦） |
| 乾卦初爻动 | 9 7 7 7 7 7 | 变卦天风姤（第 44 卦） |
| 乾为天取互卦 | 全为少阳 | 互卦仍是乾为天 |

八条全部通过。

## 边界说明

这个工具**只出卦象，不出建议**。

它算出本卦、动爻、变卦、互卦，不判断吉凶，不给行动方案。卦辞爻辞的解读需要自己查或者交给别的工具。

卦象是一个换角度看问题的由头，不替人预测账单，更不该替人做财务决定。
